Una sola verdad histórica para analizar

Un Data Warehouse integra las fuentes operacionales, las organiza por sujeto de negocio y conserva el historial. Responde cuánto vendimos por región el trimestre pasado, no cuál es el saldo de esta caja ahora mismo.

Recorre Inmon, OLTP/OLAP, staging → marts, ETL/ELT, grano y estrella, SCD y bus matrix, OLAP — con citas de Designing Data-Intensive Applications (Kleppmann, Ch.3: warehouse, star/snowflake, columnar) etiquetadas [DDIA], más el caso retail.
